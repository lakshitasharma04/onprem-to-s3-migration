\# On-Prem to AWS S3 Data Migration (Free Tier)



\## Project Overview

This project demonstrates how on-premise enterprise data can be migrated to AWS S3 using the AWS CLI.  

It simulates a real-world data migration scenario with cost optimization using S3 Lifecycle policies.



\## Architecture

\- Local machine (on-prem simulation)

\- AWS S3 bucket

\- AWS CLI for data transfer

\- S3 Lifecycle rules for cost optimization



\## Tools \& Services Used

\- AWS S3

\- AWS CLI

\- IAM (Access Keys)

\- Windows CMD
